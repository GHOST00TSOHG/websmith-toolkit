ThinkingOrbs

Nine dotted, honestly-3D “thinking” indicators for AI and agent UIs. Two tuned sizes, light and dark. Live canvas, no CDN — the official thinking-orbs 0.3.2 engine, MIT.

Status labels

Drop into a project

npm install thinking-orbs

import { ThinkingOrb } from "thinking-orbs";

<ThinkingOrb state="searching" size={64} />
<ThinkingOrb state="working" size={20} />

SwiftUI (iOS 17+): add package https://github.com/haplollc/ThinkingOrbs, then ThinkingOrb(.searching) or ThinkingOrbLabel("Searching the web…", design: .searching). See README.md and HOW-TO-MAKE.md in this folder.
